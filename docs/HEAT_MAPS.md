# Heat Maps

Collection 04 displays the station-anchored 95th percentile of monthly maximum temperature
for January, February, March, October, November and December over 2000–2025. A common
22–42 °C blue–yellow–red display scale supports direct visual comparison among months.

Web images are averaged display derivatives of the analytical GeoTIFFs. Numerical inspection
uses aligned, quantized browser grids; native-resolution analysis must use the source GeoTIFFs.
